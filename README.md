## Featured projects
- 🚀 **[R-Type](https://github.com/Miou-zora/R-Type)** — C++ multiplayer shoot 'em up built on our own ECS engine, networked over UDP. I wrote the network client (message queue, acknowledgement system).
- 💡 **[Raytracer](https://github.com/ripel2/OOP_raytracer_2023)** — C++ 3D rendering engine with plugin-based primitives and lights. I added multithreaded rendering, supersampling anti-aliasing and Phong lighting.
- 🍕 **[Plazza](https://github.com/FoxaxeWasTaken/plazza-de-la-mama)** — C++ pizzeria simulation: kitchens as processes, cooks as threads in a thread pool, inter-process communication through named pipes.
